# 프로젝트 상세 슬라이드 넣는 곳

각 프로젝트 영역은 이 폴더의 이미지를 **파일명 순서대로** 세로로 이어 붙여 만듭니다.

## 파일 규칙

```
assets/slides/01/01.jpg, 02.jpg, 03.jpg ...   학원 ERP 서비스 고도화
assets/slides/02/01.jpg, 02.jpg, 03.jpg ...   시니어 AI 케어 서비스 기획
assets/slides/03/01.jpg, 02.jpg, 03.jpg ...   숏폼 OTT 서비스 런칭
assets/slides/04/01.jpg, 02.jpg, 03.jpg ...   케이크 주문 서비스 구축
```

- 파일명은 **두 자리 zero-padding** — `01.jpg` ✓ / `1.jpg` ✗
- **01번부터 빈 번호 없이 연속**이어야 합니다. 중간이 비면 거기서 멈춥니다.
  (예: `01, 02, 04` → 02까지만 나옴)
- 확장자는 폴더별로 하나만 쓰세요. `jpg` `jpeg` `png` `webp` 중 자동 인식합니다.
- **장수는 어디에도 적을 필요가 없습니다.** 파일을 넣고 새로고침하면 끝입니다.
- 이미지는 원본 비율 그대로 렌더링됩니다(잘리거나 늘어나지 않음).
- 권장 내보내기: 원본 슬라이드가 1920 × 1080 이므로 그대로, JPG 품질 80 전후.

## Figma 레이어 ↔ 폴더 매핑

| 폴더 | Figma 프레임 | 원본 레이어명 | Figma 기준 장수 | 현재 |
|---|---|---|---|---|
| `01/` | `Strategy section` (215:73900) | `content - 01` | 1 | **1장 있음** |
| `02/` | `02 시니어 AI 케어 서비스 기획` (215:73935) | `웅진씽크빅-1 … -18` | 18 | 비어 있음 |
| `03/` | `03 숏폼 OTT 서비스 런칭` (215:73955) | `위치박스-1 … -20` | 20 | 비어 있음 |
| `04/` | `04 케이크 주문 서비스 구축` (215:73977) | `주문제작케이크-1 … -33` | 33 | 비어 있음 |

> ⚠️ `03/` 의 Figma 레이어 순서는 이름순이 아닙니다
> (`위치박스-1,2,3,4,5,14,15,16,17,18,6,7,8,9,10,11,12,13,19,20` 순으로 쌓여 있음).
> 캔버스에서 **위에서부터 보이는 순서대로** `01.jpg` 부터 붙여주세요.
